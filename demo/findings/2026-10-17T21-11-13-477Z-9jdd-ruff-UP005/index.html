Rule analysis

Flags usage of deprecated unittest method aliases like assertEquals, assertNotEquals, etc.

Fix: Replaces deprecated unittest method aliases with their non-deprecated counterparts (e.g., assertEquals → assertEqual, assertNotEquals → assertNotEqual, failUnless → assertTrue, failIf → assertFalse, assertRaisesRegexp → assertRaisesRegex, assertRegexpMatches → assertRegex).

12 hazards
  • Rewriting self.assertEquals to self.assertEqual changes behavior if a subclass overrides assertEquals but not assertEqual, breaking polymorphism.
  • If 'self' is not a TestCase instance (e.g., a mock or wrapper), the rewritten method may not exist, causing AttributeError.
  • Comments attached to the deprecated method name (e.g., self.assertEquals # TODO) are lost during token replacement.
  • In dynamically generated code via exec() or eval(), the string 'assertEquals' may be referenced elsewhere, and rewriting breaks string-based lookups.
  • If a variable named 'assertEquals' exists in local scope (e.g., assertEquals = 5), the rewrite incorrectly modifies it to 'assertEqual', causing a NameError.
  • When using getattr(self, 'assertEquals') dynamically, the rewrite does not update the string argument, causing a mismatch.
  • In code that inspects method names via __dict__ or dir(), the renamed method alters introspection results, affecting frameworks that rely on deprecated names.
  • If the code runs under Python <3.12 where deprecated aliases still exist, the fix is unnecessary but harmless; however, in rare cases of custom unittest subclasses that deliberately shadow the deprecated name, the rewrite may bypass intended overrides.
  • Rewriting assertRaisesRegexp to assertRaisesRegex fails if the test framework or monkey-patched version expects the old name for plugin compatibility.
  • In code that uses functools.partial or methodcaller with the deprecated name as a string, the fix does not update those references, leading to runtime errors.
  • If the deprecated method is accessed via a class variable alias (e.g., eq = self.assertEquals), the rewrite does not propagate to the alias, leaving stale references.
  • In IPython notebooks or interactive environments where unittest is reloaded, the fix may misfire due to delayed module state.
