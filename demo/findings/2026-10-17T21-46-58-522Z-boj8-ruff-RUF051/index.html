Rule analysis

Flags 'if key in dict: del dict[key]' patterns that can be replaced with dict.pop(key, None).

Fix: Replaces 'if key in dictionary: del dictionary[key]' with 'dictionary.pop(key, None)', preserving indentation and removing the conditional block.

10 hazards
  • The original code only deletes the key when present; pop(key, None) silently ignores missing keys but otherwise behaves identically when the key exists, so no behavioral change occurs for existing keys.
  • If the dictionary expression has side effects (e.g., a function call), evaluating it twice in the condition and once in the fix could change behavior if the function mutates state or returns different values.
  • If the key expression has side effects (e.g., a function call), evaluating it twice in the original versus once in the fix alters the number of side effects.
  • If the dictionary or key expression raises an exception during evaluation, the original may raise it in the condition while the fix may raise it during the pop call, changing when the exception occurs.
  • If the dictionary is aliased elsewhere, both versions mutate the same object, so no difference in aliasing behavior.
  • If the del statement is inside a try-except block that catches KeyError, replacing it with pop may silence the exception where the original would have propagated it (though the condition prevents KeyError in the original).
  • If the block contains comments, the fix may discard them as the rule marks fixes unsafe when comments are present in the if statement.
  • If the dictionary is a property or descriptor with __delitem__ side effects, pop may invoke different internal logic than direct deletion, potentially altering behavior.
  • If the key is unhashable, both the condition and the del/pop will raise TypeError at the same point, so no difference in error timing.
  • If the code relies on the KeyError being raised for missing keys (e.g., in a broader try-except), the original condition prevents entry so no error occurs, matching pop's silent ignore.
