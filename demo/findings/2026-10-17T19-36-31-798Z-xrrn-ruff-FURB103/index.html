Rule analysis

Flags manual file writes using 'open' + 'write' inside a 'with' block when they can be replaced with pathlib.Path.write_text/write_bytes.

Fix: Replaces the 'with open(...) as f: f.write(...)' block with 'Path(...).write_text(...)' or 'Path(...).write_bytes(...)' based on mode, adding 'from pathlib import Path' if needed.

10 hazards
  • Removes comments attached to the 'as f' alias or within the with block, as the fix discards the original statement structure.
  • Changes behavior if the file mode includes '+' (e.g., 'w+') since write_text/write_bytes only open for writing, not reading.
  • Alters behavior when the write call is not the last statement in the block, as later statements in the original with block would be dropped.
  • Breaks code if the file variable 'f' is used after the write within the block (e.g., for seeking or telling), since the variable is eliminated.
  • May fail if the path expression has side effects (e.g., a function call) and is evaluated multiple times due to context manager entry/exit logic, though unlikely.
  • Incorrectly handles binary vs text modes if the mode string is dynamically constructed and not explicitly 'b' or absent, leading to wrong method choice.
  • Does not preserve custom encoding or errors parameters beyond UTF-8/default, as write_text uses defaults unless specified, risking encoding mismatches.
  • Removes the ability to write multiple times via the same handle in the block, as the fix performs a single write operation.
  • Changes timing of file closure: the original block exits cleanly via __exit__, while the fix relies on Path's internal handling, which may differ in error cases.
  • If the 'open' call is overridden or shadowed (e.g., local variable named 'open'), the fix incorrectly assumes builtin open and misbehaves.

from pathlib import Path

# Hazard 1: f is used after write for seeking

    with open('h1.txt', 'w') as f:
        f.write('abc')
        # Using f after write is the pattern we want to break
        f.seek(0)
        pos = f.tell()
    print(f"OK (old) seek={pos} tell={f.tell()}")

    print(f"OK (old) Exception: {type(e).__name__}: {e}")

# The FURB103 fix replaces this with:
