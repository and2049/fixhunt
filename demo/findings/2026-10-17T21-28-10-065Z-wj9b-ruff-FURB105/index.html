Rule analysis

Flags print() calls with empty string literals as positional arguments or redundant sep=keyword arguments.

Fix: Removes all empty string literal positional arguments and the sep keyword argument when present, preserving other arguments and keyword arguments like end, file, flush.

10 hazards
  • The sep argument might be a variable whose removal avoids evaluating it, changing behavior if it has side effects.
  • The sep argument might be a variable whose removal hides a TypeError if it is not a string or None.
  • An empty string argument might be intended to produce a specific output format (e.g., CSV with empty fields) and its removal alters output.
  • Multiple empty strings might be used for alignment or spacing in output, and removing them changes formatting.
  • If sep is a keyword argument passed via **kwargs, the autofix cannot safely remove it and may leave invalid syntax.
  • Comments attached to the empty string arguments or sep keyword may be lost during rewriting.
  • If the print statement is part of a larger expression (e.g., in a list comprehension), removing arguments could alter syntax validity.
  • The sep argument might be conditionally assigned and its removal could skip error checking in debugging contexts.
  • In code relying on exact argument count for introspection or decorators, removing args may break assumptions.
  • If sep is a built-in overridden locally, removing it may avoid using the local override and use the built-in instead.
