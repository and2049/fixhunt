Rule analysis

Flags usage of deprecated abstract base class decorators `@abc.abstractclassmethod`, `@abc.abstractstaticmethod`, and `@abc.abstractproperty`.

Fix: Replaces `@abc.abstractclassmethod` with `@classmethod` followed by `@abc.abstractmethod`, `@abc.abstractstaticmethod` with `@staticmethod` followed by `@abc.abstractmethod`, and `@abc.abstractproperty` with `@property` followed by `@abc.abstractmethod`, preserving decorator order where applicable.

10 hazards
  • Rewriting `@abc.abstractproperty` to `@property\n@abc.abstractmethod` changes evaluation order if other decorators are present above, potentially altering wrapper semantics.
  • If `@abc.abstractclassmethod` is used with a metaclass that intercepts `__new__`, replacing it may alter class creation behavior due to differing descriptor protocol timing.
  • The fix may duplicate existing `@classmethod` or `@staticmethod` decorators when they already precede the deprecated decorator, resulting in redundant or conflicting decorator stacks.
  • Comments placed between the deprecated decorator and the function definition may be lost or misattributed during rewrite if the tool does not preserve inter-decorator formatting.
  • In code using string annotations (`from __future__ import annotations`), moving decorators could theoretically affect runtime evaluation if decorators depend on annotation resolution—though unlikely, it introduces a theoretical hazard.
  • If `@abc.abstractproperty` is applied to a non-method (e.g., a module-level variable), the rewrite to `@property` will fail at runtime because `@property` requires a getter method.
  • When the deprecated decorator is used in a dynamically generated class via `type()`, the rewrite may not preserve the intended decoration order if the autofix assumes static structure.
  • If an alias like `ac = abc.abstractclassmethod` is used, the rule may not fire (due to missing name match), but if it did fire incorrectly, the fix would produce invalid syntax by inserting `@classmethod` and `@abc.abstractmethod` without context.
  • Applying the fix to nested functions inside other functions may break scoping if the autofix incorrectly lifts or reorders decorators relative to `nonlocal` or `global` statements.
  • In code that relies on the deprecated decorator’s specific `__isabstractmethod__` behavior (now emulated), subtle differences in introspection could affect frameworks that inspect ABCs directly.
