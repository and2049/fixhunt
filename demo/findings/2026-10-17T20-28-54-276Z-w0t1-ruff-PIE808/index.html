Rule analysis

Flags range() calls where the start argument is explicitly 0, since it is redundant.

Fix: Removes the first argument when it is exactly 0, transforming range(0, y) into range(y).

1 hazards
  • If 'y' contains a side effect like a function call (e.g., range(0, func())), removing the explicit 0 changes nothing but relies on correct parsing; however, if the expression were misparenthesized, it could alter grouping—though this is unlikely given grammar constraints.
