Rule analysis

The rule flags JSX boolean attributes written without an explicit value (e.g., `<input disabled />`), which implicitly evaluate to `true`, requiring them to be rewritten with an explicit boolean or falsy value.

Fix: The autofix rewrites the implicit boolean attribute by appending `={true}` to the attribute name, converting `<input disabled />` into `<input disabled={true} />`.

1 hazards
  • Rewriting `<input disabled />` to `<input disabled={true} />` changes nothing in behavior but may interfere with tools that rely on the syntactic distinction between minimized and non-minimized attributes, such as certain HTML minifiers or legacy parsers.
