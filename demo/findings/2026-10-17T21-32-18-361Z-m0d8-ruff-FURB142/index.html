Rule analysis

Flags loops that mutate a set via repeated .add()/.discard() calls when they can be replaced with bulk update()/difference_update().

Fix: Replace the loop with a single call to set.update(iterable) for .add() loops or set.difference_update(iterable) for .discard() loops.

8 hazards
  • If the loop body contains additional statements besides .add()/.discard(), removing them changes behavior.
  • If the loop variable is used after the loop, eliminating the loop may alter its final value.
  • If the iterable expression has side effects (e.g., a function call), evaluating it once vs. per iteration changes timing.
  • If the set is aliased elsewhere, the mutation timing affects concurrent readers.
  • If .add() or .discard() raises an exception, the bulk method may not replicate partial mutation state.
  • If the loop includes a break or continue, removing it alters control flow.
  • If the set is reassigned within the loop, the bulk method operates on the wrong set instance.
  • If comments exist inside the loop block, the fix may discard them when deemed unsafe.
