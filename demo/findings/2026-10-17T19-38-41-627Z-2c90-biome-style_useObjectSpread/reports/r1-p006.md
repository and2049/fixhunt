## Why the rewrite is not equivalent (model draft, verify before use)

The stack trace line numbers changed because the rewrite altered source locations; although both expressions produce identical objects, their syntactic forms differ, shifting line and column information in generated error stacks, which the program observes via e.stack parsing. This makes the transformation behaviorally different despite semantic equivalence in object construction.
