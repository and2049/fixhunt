Rule analysis

Flags single-element tuples in except clauses like 'except (ValueError,)'.

Fix: Rewrites 'except (SingleException,):' to 'except SingleException:' by removing the parentheses and trailing comma while preserving any 'as' alias, indentation, and following colon.

8 hazards
  • Removing parentheses around a single exception type changes nothing semantically but may drop inline or end-of-line comments attached to the parentheses or comma, altering source code documentation.
  • If the except clause spans multiple lines due to formatting, the fix may collapse vertical whitespace, potentially affecting readability but not execution.
  • When the single element is a starred expression like '(*args,)', the rule correctly does not fire, so no rewrite occurs; however, misidentifying a starred expression as a regular tuple would lead to incorrect removal of parentheses, breaking unpacking semantics.
  • In rare cases where the exception tuple is generated via a macro or code-generation tool that relies on the syntactic presence of a one-tuple for parsing, removing it could interfere with tooling (though this does not affect runtime behavior).
  • If the except clause is part of a larger compound statement where parentheses were mistakenly believed to be necessary for disambiguation (e.g., confused with tuple displays in other contexts), removal is still safe because Python grammar unambiguously binds the except clause.
  • The fix does not touch the 'as' target, so aliasing remains intact; however, if comments are interleaved between the exception and the 'as' keyword (e.g., 'except (ValueError, ) # note as e:'), the rewrite may disturb comment attachment though this is a formatting hazard, not semantic.
  • Should the single element be an expression with side effects (e.g., a function call), evaluating it once versus as a one-tuple makes no difference, so no semantic change occurs.
  • If the code is parsed by a tool that treats one-tuples distinctly in AST transformation (e.g., for refactoring), removing the tuple structure could alter the AST shape, potentially breaking downstream tools that expect a Tuple node with one element.
