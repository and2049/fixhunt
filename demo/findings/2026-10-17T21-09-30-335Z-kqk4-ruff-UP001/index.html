Rule analysis

Flags redundant '__metaclass__ = type' assignments in class bodies.

Fix: Removes the '__metaclass__ = type' line from the class body, preserving all other statements, comments, and formatting; if the class body becomes empty, it is replaced with 'pass'.

10 hazards
  • The rewrite removes a '__metaclass__ = type' statement that may be relied upon by a metaclass hook during class creation, altering the class's metaclass resolution.
  • If '__metaclass__ = type' is used to suppress a warning or satisfy a static analysis tool, removing it may reintroduce that warning or failure.
  • The rewrite may eliminate a '__metaclass__ = type' line that serves as a placeholder or documentation artifact, changing the intent of the code.
  • If the class contains only '__metaclass__ = type' and a comment, removing the line leaves only the comment, which may be invalid if the comment is not a valid standalone statement (though Python allows comments alone, this may affect tooling expectations).
  • In rare cases where '__metaclass__ = type' is dynamically assigned via exec or eval in the surrounding scope, removing it could affect name binding in the class's local namespace.
  • If '__metaclass__ = type' is part of a larger pattern where its presence affects the order of decorator evaluation or class decorator application, removing it could change behavior (though decorators are evaluated before the class body, this is unlikely but noted for completeness).
  • The rewrite may interfere with tools that scan for '__metaclass__ = type' as a marker for code generation or transformation, causing those tools to skip the class.
  • If '__metaclass__ = type' is used to intentionally shadow a built-in or global 'type' in the class namespace (though this is nonsensical for metaclass purpose), removing it changes the namespace.
  • The rewrite may remove a '__metaclass__ = type' line that is followed by a trailing comment on the same line, causing the comment to be lost if not handled properly by the autofix.
  • If the class body contains '__metaclass__ = type' and the autofix incorrectly removes indentation or blank lines, it could alter the visual structure and lead to parsing errors in edge cases (e.g., mixing tabs and spaces).
